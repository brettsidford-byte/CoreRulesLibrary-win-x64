# Development roadmap

## 1. Focused HTML viewer

- Books and Characters navigation
- WebHelp and exported character-sheet discovery
- Shared HTML renderer, navigation, font and scaling
- Search/filter and remembered folders
- Self-contained Windows build

## 2. Testing and refinement

- Verify all supplied books and representative character exports
- Read-only `Spells.dat` and `SpellsU.dat` browser grouped by caster type and level
- Improve legacy table layout at high display scales
- Add refresh and document error reporting
- Confirm image and internal-link compatibility

## 3. Optional packaged books

- Add an authorised local-content packaging mechanism
- Prefer packaged books when present
- Retain external WebHelp selection as a fallback
- Keep copyrighted book content outside the public source repository
